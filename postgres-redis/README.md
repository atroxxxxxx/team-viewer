# PostgreSQL сервиса заявок

Схема в `init` поднимается вместе с контейнером Postgres и принадлежит только сервису заявок. Redis в эту схему не входит: он запущен рядом с ретранслятором и хранит uuid клиента и `tunnel_id` на 15 минут.

Порт `5432` на хост не публикуется. Сервис заявок ходит к базе по имени `postgres` во внутренней сети compose.

## Секции

Заявки и связанные таблицы секционированы по `LIST (shard_id)` на `*_s0` … `*_s3`. Номер считает сервис заявок, `crc32(account_id) % 4`. Первичный ключ начинается с `shard_id`.

`shard_directory` сейчас помечает все секции как `local`. `ticket_index` — указатель `ticket_id -> shard_id`. В строке заявки лежат хеш `ticket_token` и, после утверждения, `tunnel_id`.

## ELK

СПЕЦПОМЕТКА. Elasticsearch, Logstash и Kibana сюда не входят. Сервисы пишут JSON в stdout. Сбор показан пунктиром на [диаграмме 07](../docs/README.md#d07).
