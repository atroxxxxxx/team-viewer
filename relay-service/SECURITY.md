# Безопасность ретранслятора

Контейнер на диаграмме [C4](../docs/uml/c4-container.png).

Порт `18082` принимает создание и удаление туннеля только с заголовком `Authorization: Bearer`. Пустой токен отвергается. Сравнение идёт по хешу обеих строк, чтобы длина заголовка не решала исход раньше времени.

На каждый туннель выпускаются два секрета по 32 байта. Порт `8554` читает не больше 256 байт первой строки и принимает ровно три поля: роль, uuid и секрет. Секрет клиента открывает только роль `CLIENT`, секрет оператора — только `OPERATOR`. Туннель без секретов не открывается. Секреты в журнал не пишутся.

RTSP слушает `127.0.0.1:18554`. Снаружи до него доходит только соединение, которое уже прошло сессионный порт. Тело создания туннеля ограничено 1 МБ. `GET /health` доступен без токена и отвечает только проверкой Redis.
