# Безопасность ретранслятора

Контейнер на диаграмме [C4](../docs/uml/c4-container.png).

Порт `18082` принимает создание, продление и удаление туннеля только с заголовком `Authorization: Bearer`. Пустой токен отвергается. Сравнение идёт по хешу обеих строк, чтобы длина заголовка не решала исход раньше времени.

На каждый туннель выпускаются два секрета по 32 байта. Порт `8554` читает не больше 200 байт первой строки и принимает ровно три поля: роль, UUID туннеля и секрет. Секрет клиента открывает только роль `CLIENT`, секрет оператора — только `OPERATOR`. Туннель без секретов не открывается. Секреты в журнал не пишутся.

RTSP слушает `127.0.0.1:18554`. RTSP принимает команды только от соединения, привязанного к выданному туннелю и роли. Клиент может публиковать, оператор может читать. Внешнее подключение к сессионному порту защищено TLS. Тело создания туннеля ограничено 1 МБ. `GET /health` доступен без токена и отвечает только проверкой Redis.
