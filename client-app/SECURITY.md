# Безопасность клиента и оператора

Окна на диаграмме [C4](../docs/uml/c4-container.png).

Оба окна только исходящие. Входящий RTSP они не слушают. ffmpeg на клиенте принимает локальный мост на `127.0.0.1`, мост сам подключается к сессионному порту.

Клиент ставит в первую строку секрет из своей сессии. Оператор ставит секрет из ответа захвата. Чужой секрет окно не получает и не подставляет. Без секрета длиной 64 символа мост не стартует.

Ввод на клиенте идёт через `xdotool` аргументами процесса, без оболочки. Текст с управляющими символами не исполняется. Код клавиши — латиница, цифры и `_`. Координаты ограничены. Источник экрана для ffmpeg — дисплей вида `:0`, произвольная строка из окружения туда не попадает.

Файл настроек окна не хранит пароль и токен заявки. Манифест моделей принимается только если каждый путь остаётся внутри каталога моделей.
