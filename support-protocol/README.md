# Общий контракт

Пакет `support_protocol` используют клиент и оператор. Здесь проверка намерения, текста шага и события ввода, HTTP-клиент сервиса заявок и аргументы ffmpeg для одного RTSP-пути.

`load_endpoints` читает `config.yaml`: схема и адрес заявок, хост и сессионный порт ретранслятора, логин, пароль и `tls_verify`. `TicketAPI` шлёт Basic и, после создания заявки, заголовок `X-Ticket-Token`. `LocalRTSPBridge` принимает ffmpeg на `127.0.0.1` и отдаёт поток в сессионный порт после строки `CLIENT` или `OPERATOR`.

Правила совпадают с кодом в `policy.py` и с описанием в `safety-policy`. Запрещённые намерения включают удаление, оболочку (`run_shell`), стойкий доступ и выгрузку секретов. Scope сравнивается по точному слову: `pointer`, `key` или `text`. Текст события не длиннее 200 символов, шаг плана — 500. Проверка оператора не заменяет проверку клиента.
