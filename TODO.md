# Планы

## Планы

- Публичный HTTPS Let's Encrypt. Выпуск уже есть у входа сервиса заявок. Имена из `.env` должны резолвиться в эту машину, а порт 80 на время выпуска должен быть открыт снаружи.
- Вынос секции PostgreSQL на другой узел. Номер секции считается как `crc32(account_id) % 4`, в `shard_directory` есть поле `dsn`. Сейчас все четыре секции локальные, сервис пишет в один пул.
- Сбор JSON из stdout в ELK. На [диаграмме 07](docs/README.md#d07) это пунктир.
- Корпус обучения и дообучение своей модели. Журнал `action_log` пишется. Выгрузка на [диаграмме 06](docs/README.md#d06) — пунктир.
