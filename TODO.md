# Планы и известные ошибки

## Планы

- Публичный HTTPS Let's Encrypt. Выпуск уже есть у входа сервиса заявок. Имена из `.env` должны резолвиться в эту машину, а порт 80 на время выпуска должен быть открыт снаружи.
- Вынос секции PostgreSQL на другой узел. Номер секции считается как `crc32(account_id) % 4`, в `shard_directory` есть поле `dsn`. Сейчас все четыре секции локальные, сервис пишет в один пул.
- Сбор JSON из stdout в ELK. На [диаграмме 07](docs/uml/07-log-shipping.md) это пунктир.
- Корпус обучения и дообучение своей модели. Журнал `action_log` пишется. Выгрузка на [диаграмме 06](docs/uml/06-training-journal.md) — пунктир.

## Ошибки

- Повторный запрос управления во время `remote_control` создаёт грант `pending`, а выбор гранта сначала берёт `pending`. Ввод после этого получает отказ, хотя прежний грант ещё `active`. См. `ActiveGrant` и `RequestControl` в `ticket-service/internal/store/session.go`.
- Отметка шага «вижу на экране» пишет наблюдение вне транзакции, которая меняет статус шага. Если обновление шага не проходит, текст наблюдения остаётся. См. `CompleteStep` в том же файле.
- Клиент ставит фазу `applied` до запуска `xdotool`. Если программа не стартовала, в журнале всё равно успех. См. `_apply_input` в `client-app/client_app/window.py`.
